## About The Project

![Loup Solitaire](/static/ls_logo.png)

Loup Solitaire est un univers d'heroic fantasy qui s'est tout d'abord développé sous la forme d'une série de livres-jeu écrite par Joe Dever et dont les huit premiers tomes, parus dans la collection Un livre dont vous êtes le héros, ont été illustrés par Gary Chalk

Je choisis de réaliser ce projet afin de jouer plus facilement à ces livres-jeux qui m'ont tant inspirés dans ma jeunesse et pourquoi pas, de faire découvrir cet univers à d'autres.


### Built With

1. Python
2. Streamlit
